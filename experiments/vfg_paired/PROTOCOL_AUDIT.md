# VFG Paired 七数据集协议审计

审计对象：原始 ViT4TS、上一版 VFG 实现与当前 `vfg_paired` 的配置、运行器、汇总器、缓存接口和 CPU 测试。未运行 GPU，也未读取或讨论任何多变量数据。

## 结论

当前实现可以运行一个**转导式、缓存复用、仅修改基础 Patch 尺度**的 A–E 对比。B–E 在基础 Patch 分支共享同一个逐查询参考窗口池，C/E 保存了视觉候选 Patch 到真实参考窗口、Patch 和时间列的对应关系，重叠排除也正确。没有发现标签被送入特征、参考、候选或校准过程。

以下结论可以直接解释：

- C 相对 B：在相同视觉参考池及相同视觉 Top-5 候选上增加全窗口 FFT 联合距离。
- E 相对 C：在相同参考池、Top-5、联合公式和权重下，将全窗口 FFT 换为局部 STFT。这是当前最干净的频率定位消融。
- A 可精确复现上一版 Stable ViT4TS 的稳定化视觉分数，数值修复没有被计作 paired 模型收益。

以下结论目前不能单独由该实验支持：

- D 优于 C/E 不能直接归因为“频域引导位置更好”。D 先选 5 个窗口，再在 `5×196=980` 个视觉 Patch 中取最小值；C/E 最终只在 5 个视觉 Patch 候选中取联合距离。候选单位和容量不同。
- B 优于 A 不能只归因为真实成对参考。A 使用 196 个跨窗口中位数 Patch，B 使用最多 `32×196=6272` 个真实 Patch，参考形式与候选容量同时变化。
- 当前 runtime 不能解释为各模型端到端推理时间。它排除了图像生成和 CLIP 提取，且共享工作在 A–E 间的归账不对称。

因此，本协议适合报告关联性结果和生成后续假设；若 D 的优势是论文主论点，必须补充候选容量匹配对照和独立端到端计时。

## A–E 实际协议

所有版本复用同一视觉缓存，使用窗口 224、步长 56、14×14 基础视觉网格；大尺度与中尺度始终使用全序列窗口中位数参考，并以相同 stable harmonic 聚合。A–E 只在基础 Patch 分支不同，最终都按 `(large + mid + base_patch) / 3` 恢复逐点分数。

| 版本 | 基础 Patch 参考和匹配 | 频域 | 可公平回答的问题 |
| --- | --- | --- | --- |
| A Stable median | 对整条待测序列的所有窗口逐 Patch 取中位数，形成 196 个合成参考 Patch；每个查询 Patch 与这 196 个参考取视觉最小距离 | 无 | Stable 基线复现 |
| B Paired visual | 对每个查询窗口，从非重叠窗口中按窗口平均视觉特征选最多 32 个；在其中全部真实 Patch 上取视觉最小距离 | 无 | paired 参考整体相对 A 的效果，但包含参考容量变化 |
| C Paired FFT joint | 与 B 相同的逐查询窗口池；先从全部真实 Patch 中选视觉 Top-5，再按候选真实窗口和候选 Patch 列取得全窗口 FFT 特征，计算联合距离后取最小 | 224 点 Hann FFT，`λ=0.3` | 相对 B 的全窗口频域联合距离收益 |
| D FFT-guided reference | 与 B 相同的窗口池；按全窗口 FFT 距离选 5 个窗口，再在这 5 个窗口的全部 980 个 Patch 上做纯视觉最近邻 | 仅用于选窗口，无联合距离和 `λ` | 频域窗口筛选整体效果；不能与 C/E 解释成只改变融合位置 |
| E Paired STFT joint | 与 C 完全相同的视觉 Top-5 Patch 身份及配对方式，联合距离改用与查询/参考 Patch 列对应的局部 STFT | 64 点局部 STFT，`λ=0.3` | 局部频率定位相对全窗口频谱的效果 |

C/E 的联合式为 `0.5 × min_k(Dv + λ × c × Df)`。`c` 分别由该序列所有 Top-5 候选的无标签视觉/频域距离稳健中位数比得到，是每条序列、每种频域表示各一个标量。`λ=0` 有显式分支，逐位恢复 B。

## 重叠排除与共同窗口池

第 `i` 个窗口覆盖半开区间 `[56i, 56i+224)`。查询 `q` 和参考 `r` 不重叠，当且仅当：

```text
|56q - 56r| >= 224
<=> |q-r| >= 4
```

实现的 eligible mask 正是 `abs(q-r) >= 4`，所以排除了查询本身和索引差 1、2、3 的全部重叠窗口。差 4 的窗口首尾相接但不共享样本，允许进入参考。

“共同 32 窗口池”的准确含义是：**每个查询窗口都有一个查询相关、最多 32 个窗口的池，且 B/C/D/E 共用这个池**。它不是整条序列固定的一组 32 个窗口。候选按查询与参考窗口的平均视觉 Patch token 余弦距离排序；短序列或边界处可少于 32 个。池只使用输入特征，不使用标签。

该设计消除了 B–E 基础 Patch 分支的直接自匹配和邻近窗口复制，但没有让整个模型变成严格的样本外检测：

- A 的三个视觉尺度都由包含查询窗口的整条待测序列中位数构建。
- B–E 的 large/mid 两个公共尺度仍使用包含查询窗口的整条序列中位数；只有 base Patch 分支使用重叠排除。
- 参考选择、频域校准、阈值统计都观察完整待测序列，属于无标签转导式评测。

因此，源码顶层“every paired method excludes the query window”的表述只对 B–E 的基础 Patch 分支成立，不适用于最终三尺度分数。

## C/E Patch 配对与 D 窗口选择

C/E 先在共同窗口池的全部真实 Patch 中取每个查询 Patch 的视觉 Top-5。每个候选同时保存：

- 真实参考窗口 ID；
- 真实参考 Patch ID；
- 参考时间列 `patch_id % 14`。

查询频域特征使用查询 Patch 的列 `query_patch_id % 14`，参考频域特征使用被选中候选 Patch 的列。这个索引链保持了跨模态候选身份，没有把独立中位数视觉参考与独立中位数频率参考错误配对。

D 在共同视觉池内部，用全窗口 FFT 的 shape+energy 余弦距离选最近 5 个真实窗口。随后不再使用频域距离，而在这些窗口的全部 Patch 中做视觉最近邻。D 的 5 是“窗口数”，C/E 的 5 是“每个查询 Patch 的候选 Patch 数”，两者不能称为相同 Top-5 容量。

## FFT/STFT 索引

### 全窗口 FFT（C、D）

- 输入是整条序列一次线性去趋势后的 224 点窗口，没有逐窗口 Min-Max。
- 使用长度 224 的 periodic Hann 窗和 `rfft`。
- 保留 `[1:113]`，即非直流 bin 1–112，包含 Nyquist bin；归一化频率为 `k/224` cycles/sample。
- 同一 112 维频谱重复到 14 个视觉列，所以它没有窗口内时间定位。D 读取重复后的第 0 列，数值上等价于直接使用该全窗口频谱。

### 局部 STFT（E）

- 224 点窗口左右各 reflect-pad 24 点，随后以帧长 64、hop 16 做 14 帧 periodic-Hann `rfft`。
- 第 `j` 帧在原窗口坐标覆盖 `[-24+16j, 39+16j]`，中心为 `7.5+16j`；这与每个宽 16 点视觉列的中心一致。
- 保留 `[1:33]`，即非直流 bin 1–32，包含 64 点 FFT 的 Nyquist bin；归一化频率为 `k/64` cycles/sample。
- 前后边界 3 帧分别依赖反射填充，边界案例应按这一事实解释。

FFT 与 STFT 都先对幅值取 `log1p` 形成 shape，并另外计算低/中/高三段 log-energy 加常数 anchor；shape 与 energy 各自归一化后拼接。全窗口 FFT 与 STFT 的 bin 数和频率分辨率不同，因此 E−C 同时代表局部定位、窗长及频率分辨率的组合变化，而不是单一“是否局部”。

## 评价聚合

评价沿用原协议：逐点分数先做 EWMA，采用全序列 mean+std 阈值，固定 `α ∈ {0.1, 0.01, 0.001}`。每条序列按区间重叠计算 TP/FP/FN 和 contextual F1。

严格聚合顺序为：

1. 对每个 `dataset × model × alpha`，对该数据集所有完整序列的 contextual F1 做无权平均。
2. 在数据集级均值上选择 F1 最大的 alpha；并列时按配置顺序优先 0.1、再 0.01、再 0.001。
3. 对选出的 6 个真实数据集值做 `real_6` 宏平均；另对 7 个数据集值做 `all_7` 宏平均。
4. 不允许用“每条序列先选最佳 alpha 再平均”的旧式聚合。

结果表中的 TP/FP/FN 是在数据集所选 alpha 下跨序列求和，而 F1-max 是逐序列 F1 的无权均值；不能用汇总 TP/FP/FN 反算该 F1。该 contextual 计数也不是一对一事件匹配：多个检测段可同时命中同一个真实事件，一个检测段也可覆盖多个真实事件。所有模型一致使用此规则，所以可用于原协议横向比较，但应避免把 TP 数解释为唯一恢复事件数。

选择最佳 alpha 明确使用测试标签，这是 F1-max 指标本身允许的后验模型评价，不是无标签推理的一部分。它不能支持“部署时无需标签即可选阈值”的表述。标签还用于事后 failure plots 与事件恢复统计，这些路径不回流到分数计算。

## 审计判定

- **标签直接泄漏：未发现。** 模型后端只接收 `timestamp/value`、视觉缓存与无标签上下文；ground truth 只在分数生成后进入评价。
- **直接自匹配：B–E 的 base Patch 未发现。** `abs(q-r) >= 4` 同时排除了自身和所有共享原始样本的窗口。A 及公共 large/mid 仍是 self-inclusive median reference。
- **候选容量混淆：存在且显著。** 尤其 D 对 C/E、B 对 A，必须限制机制性表述。
- **运行时间误导风险：存在且显著。** 当前分项数据可用于剖析共享缓存后的计算，不能作为 A–E 公平端到端延迟排行。
- **评价聚合：实现符合数据集级 Unweighted Contextual F1-max。** 应同时报告六真实集和七数据集宏平均，并保留 125 条完整性门禁。

在补充容量匹配与独立计时前，建议将 paired 实验标记为“机制诊断”，不要把 D 的任何领先直接写成频域引导匹配优于联合重排的因果证据。
