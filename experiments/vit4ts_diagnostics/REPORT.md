# ViT4TS 第一阶段复现实验报告（2026-10-16）

## 结论

固定 OpenAI CLIP ViT-B/16，不运行 Qwen、不改 ViT4TS 网络。75 条序列、三种基础配置、两种时间映射已全部完成；5 个 GPU 工人无失败，总耗时 495 秒。另做了数据去重和 q=0.25 行分位数后处理诊断。每条序列的异常分数、预测区间与 TP/FP/FN 都已保存。

不存在一个能同时解释三组数据与论文差距的单一参数：224/56 明显提高 AdExchange，却降低 AWS 和 SMAP；修正时间映射几乎不改 F1；把预处理顺序改为论文文字但保留公开代码固定 [0,1] 绘图，会造成大量点超出画布范围并降低 F1。SMAP 的另一项重要差异是论文写的行分位数与代码的“最高 25% 均值”：独立后处理诊断在 224/56 下将 SMAP F1 从 0.523 提至 0.644，仍低于论文 0.726。固定 OpenAI 权重与论文 LAION-400M 权重不同，且论文与公开代码在多尺度融合等处还有差异，因此不能宣称严格复现论文数值。

## 单因素影响

1. 窗口：相对 240/60，224/56 的 F1-max 在 AdExchange +0.158、AWS -0.019、SMAP -0.089。窗口是 AdExchange 差距的主要已验证来源；对 SMAP 的作用相反。三组数据均按预设配置完整评价，未按测试标签挑选配置。
2. 时间映射：240/60 的官方 stitch 实际按 224/56 叠加，随后整段插值回原时间长度。修正后在 AdExchange F1 不变、AWS +0.003、SMAP 不变；224/56 下两种映射相同。所有 1350 个评价行只有两行 F1 变化，具体区间保存在对应 JSON。它不是主要差距来源。
3. 预处理及绘图范围：公开代码先去趋势再 Min-Max，并固定 [0,1] y 轴。仅把顺序改为“先 Min-Max 后去趋势”时，AdExchange 4848/7967、AWS 44941/67666、SMAP 310603/562800 个点落在画布范围外；平均异常分数的相关性下降，三组 F1 均降低。若随后按处理后序列真实 min/max 绘图，先后两种顺序在数学上仅差正仿射变换：75 条序列重新归一化最大差小于 9e-16，三组抽查图像像素完全相同。因此观察到的性能变化主要来自“预处理顺序×固定绘图范围”的相互作用。
4. 去重：AdExchange 与 AWS 原始 CSV 分别比论文 Table 4 多 2、22 行，恰为重复时间戳数；SMAP 点数完全一致。去重保留首次或末次值，AdExchange F1 仍为 0.5167，AWS 从 0.4795 变成 0.4769。论文的点数与唯一时间戳数相同，但论文未说明去重策略，不能推断其实际处理方式。该差异不是主要 F1 来源。
5. 评价：作者仓库对一条预测同时覆盖多个真区间时按覆盖个数计 TP；当前项目按一条预测计一个 TP，后者符合论文公式。对此次 1350 行评价，两套 TP 计数完全相同，因而不影响当前结果。作者仓库的 F1-max 是“每条序列先取三 α 最优，再平均”；论文主表是“固定 α 先对序列平均，再取三 α 最高”。官方 240/60 的前一口径分别为 AdExchange 0.700、AWS 0.565、SMAP 0.707，不能拿来直接对比论文 0.615/0.400/0.726。

## 额外后处理诊断

在 224/56、同一 OpenAI CLIP、相同预处理下，重新用公开代码输出的 224×224 异常图进行二维重叠平均，再取每个时间点的行 25% 分位数；唯一变化是异常图聚合方式。

| 数据集 | 代码聚合 F1-max | 行分位数 F1-max | 行分位数 P/R | 论文 ViT4TS |
|---|---:|---:|---:|---:|
| AdExchange | 0.674 | 0.667 | 0.800 / 0.600 | 0.615 |
| AWS | 0.460 | 0.564 | 0.668 / 0.588 | 0.400 |
| SMAP | 0.523 | 0.644 | 0.618 / 0.737 | 0.726 |

完整数值及 75 条结果在 quantile_diagnostic/。此诊断使用公开代码已经上采样到 224×224 的图；论文文字中的 patch 分辨率及融合步骤并未完整公布为可直接替换的代码。因此 0.644 是后处理诊断结果，不是论文原实现复现。

## 数据和可复查性

- 有效序列：AdExchange 5、AWS 17、SMAP 53；总点数 7967、67666、562800；真异常区间数 11、30、67，与论文异常区间数一致。
- 所有输入时间戳已排序，所有值有限；重复时间戳仅出现在上述两个 NAB 组，全部 108 个真异常区间的端点都能在数据中找到。
- 官方 240/60 配置与先前保存的 75 条 ViT4TS 结果逐项一致，0 个 F1 不一致；额外行分位数诊断重新推断时，75 条源聚合分数与本轮 224/56 缓存完全一致。
- 源码与数据校验值见 manifest.json；官方源码参照见 official_reference；本次代码在 experiment.py、supervisor.py、summarize.py、dedup.py、quantile.py。所有实验结果在本独立目录，原 src/ 与既有结果未被覆盖。

## 解释边界

论文主实验使用 LAION-400M 预训练的 OpenCLIP ViT-B/16，本实验按要求固定 OpenAI CLIP ViT-B/16，未比较权重。论文还描述 harmonic 多尺度融合，而公开代码为三尺度算术平均；这涉及未获授权修改的算法路径，本轮只记录差异，不把未测试因素归因为已证实原因。尤其 SMAP 在窗口和预处理控制实验后仍低于论文，不能据此断言单靠某一项修改就能达到论文数值。
